# Messho SC Attendance Android App

This project wraps the current Messho SC Attendance website in an Android WebView.

Features:
- Employee ID + PIN
- Supabase attendance database
- GPS office-radius verification
- Weekly-off and holiday blocking
- Check-In / Check-Out

Office GPS:
Latitude 19.307765
Longitude 73.071277
Radius 150 meters

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install the generated debug APK on an Android phone.

The HTML is stored at:
app/src/main/assets/index.html
